# 你是谁

[English](README.md) · **简体中文**

网站眼中的你是谁？[你是谁](https://who.1ms.dog) 运行任何网站在你打开它的那一刻都能运行的嗅探器，全程不弹任何授权提示，然后把结果写成一段填空的话：你可能的国籍、所在城市、语言和时区、设备、浏览器、屏幕和显卡、网络、偏好、从字体看出的职业，以及浏览器指纹。

接着它像网站识别伪装那样，把这些信息互相对比；并列出全部 133 个嗅探器、每个的读取方式和读到的结果。

另外几组读数：本站探针 probe.1ms.dog 直接读你的连接（TCP 包的系统、MTU 和 JA4T，TLS 的 JA4/JA3，HTTP/2 和 HTTP/3 的开头），IPv6 是否泄露网卡 MAC；谎言检测（54 个接口有没有被改写、iframe 对照）和「防护是谁」；渲染与引擎指纹（元素尺寸、WebGL 图像、WebGPU、编解码器、ICU、滚动条、CSS 版本、字体平滑等）；存储留痕、ETag 缓存编号、跨浏览器硬件编号，以及每一项有多常见；要点按钮才做的追踪拦截实测、精确定位和运动传感器；还能和朋友的分享画像逐项对比。

**在线使用：** https://who.1ms.dog · 专题页：[浏览器指纹检测](https://who.1ms.dog/zh-cn/fingerprint/)、[DNS 泄露检测](https://who.1ms.dog/zh-cn/dns-leak/)、[浏览器环境检测](https://who.1ms.dog/zh-cn/browser-check/)、[时区检测](https://who.1ms.dog/zh-cn/timezone-check/)、[代理检测](https://who.1ms.dog/zh-cn/proxy-check/)、[浏览器语言检测](https://who.1ms.dog/zh-cn/language-check/)、[Canvas 指纹检测](https://who.1ms.dog/zh-cn/canvas-fingerprint/)、[UA 检测](https://who.1ms.dog/zh-cn/user-agent/)、[浏览器扩展检测](https://who.1ms.dog/zh-cn/extensions/)、[WebRTC 泄漏检测](https://who.1ms.dog/zh-cn/webrtc-leak/)（同一个工具，把那一项结果放在最前面；文案在 `src/pages.mjs`）

## 能看到什么

- **画像**：一段话，每个空都由嗅探器填上。鼠标放在空格上，会显示它来自哪些嗅探器（对应的行会高亮）。只有年龄是留空的：浏览器里没有任何地方透露年龄，页面会直接说明，而不是瞎猜。
- **网站会怎么想**：画像里有三个空不是读数而是结论：这台机器像是干什么用的（显卡和刷新率）、各处说法对不对得上（对不上就说网站多半会猜你在用代理）、清 Cookie 有没有用（指纹稳不稳）。
- **和上次比**：只记在你的浏览器里，改完设置再测，会显示「上次 8 处，这次 7 处，修好了：…」。指纹变了时，会说是浏览器升级了，还是哪几项变了。
- **最近几次**：最近 10 次的暴露数画成一条小折线，鼠标放在点上看是什么时候测的。同样只存在你的浏览器里。
- **复制文字**：把画像、12 项检测和连接协议复制成一段文字，城市、网络和 IP 自动打码，末尾带本站链接，方便贴到论坛。
- **按系统给修法**：DNS 泄露和 WebRTC 的「怎么修」按你的系统写：Windows、macOS、iPhone、安卓各有对应的客户端和设置。
- **系统识别**：鸿蒙的浏览器（ArkWeb）为了兼容会在 UA 里写 Windows 或 Android，按 OpenHarmony、HarmonyOS、ArkWeb 标记识别成鸿蒙。
- **想装成在哪儿上网**：选一个目标地区（默认是 IP 所在地），逐项看 IP、系统时区、浏览器语言、DNS、WebRTC 还差什么，以及怎么改。
- **伪装检测**：想隐藏自己时最要紧的 12 项，并按结果给出 A 到 F 的环境评分：
  - 系统时区和 IP 所在时区
  - 浏览器语言和 IP 所在国家
  - 系统语言和 IP：Windows 装了哪国的语言包，从补充字体、本地语音和键盘布局看得出来（其他系统默认带齐各国字体和语音，看不出）
  - DNS 泄露：实际替你解析域名的 DNS 解析器在哪个国家，和 IP 是否一致
  - 分流：国内网站、国外 IP 服务、ChatGPT、Claude、Cloudflare 和本站看到的出口是否不同
  - WebRTC：STUN 服务器看到的公网地址，本站通过 IPv4 和 IPv6 都没见过的就算泄漏
  - 延迟与连接：浏览器测到的往返时间比 Cloudflare 在自己连接上测到的长很多，说明中间还有一段，像是代理（住宅 IP 也藏不住）
  - 机房网络（云、托管、VPN 服务商）
  - User-Agent 和 Client Hints、WebGL 显卡暴露的真实系统
  - 环境被篡改：navigator 属性被重新定义、画图和音频函数被替换、JS 引擎和 UA 对不上、请求头和 JS 里的语言不同、Date 和 Intl 的时区不同
  - 指纹是稳定的（可追踪）还是随机的
  - 自动化（`navigator.webdriver`），以及 AI 代理或脚本在操作：鼠标每次都直接跳到目标上点击、之前没有移动轨迹，或者页面收到了不是浏览器发出的点击（FP-Agent，arXiv 2605.01247）

  每一项会暴露你的检测都附有**怎么修**（DNS 泄露用 Clash 的 fake-ip 或 TUN、限制 WebRTC、改时区……）；页面由 1ms.dog 托管时，还会直接链到能查得更深的工具（`<meta name="dns">`、`"egress"`、`"ipqs"`）。
- **连接协议**：放在检测下面，判断方式相同，但不计入暴露数，因为它们说的是连接怎么建立，不是你是谁：
  - HTTP/3：本站的 `/cdn-cgi/trace` 隔一会儿再问几次，有一次走了 QUIC 就算可用；一直没有时看 WebRTC 的 STUN（UDP）通不通，UDP 也不通才判为被挡或代理不转发 UDP，否则只说「还没切换」
  - ECH：本站在 DNS 的 HTTPS 记录里发布了 ECH 配置，trace 的 `sni=plaintext` 就说明浏览器没用上；按浏览器给出最可能的原因（Safari 不支持、Firefox 要开 DoH、其余多半是 DNS 没返回 HTTPS 记录，比如代理的 fake-ip）
  - 后量子密钥交换：默认支持它的浏览器（Chromium 124、Firefox 132、Safari 26 起）却用了经典算法，说明中间可能有东西自己建了 TLS
  - WARP 和 Gateway：只说明，不判好坏
- **指纹卡**和上次来访：只记在你的浏览器里，显示你上次什么时候来、指纹变没变。网站不用 Cookie 也能认出你，靠的就是这个。
- **分享**：在浏览器里画出的图片卡片（可下载、可复制），和一个 `/r/<code>` 链接：打开后看到同样的画像（用打开者的语言），在聊天软件里的预览卡片会把结论写进标题和图片（由 Worker 生成；格式和版本号见 `src/share.mjs`）。图片和链接都不含你的地址和指纹，城市和运营商只有勾选后才带上。托管方提供短链服务时（`<meta name="shortener">`）会自动缩短。
  打开别人分享的画像时，指纹卡的位置换成一张「测测我自己」的卡片，底部按钮也换成实心的。
- **全部嗅探器**，分组列出：
  - *服务器看到的*：IP、Cloudflare 地理位置（城市、坐标、ASN、时区）、反向解析、最近的边缘节点和 TCP 往返时间、HTTP/TLS 版本和加密套件、抗量子密钥交换和 ECH、Cloudflare WARP、TLS ClientHello 指纹、你的时钟偏差、DNS 解析器（edns.ip-api.com）、WebRTC 公网和内网地址
  - *出口*：每类目的地看到的地址，以及 IPv4 和 IPv6 出口（Cloudflare Radar）
  - *请求头*：User-Agent、Accept-Language、Sec-CH-UA、平台、压缩方式、DNT/GPC、来源页
  - *语言和地区*：`navigator.languages`、区域设置、时区、12/24 小时制、每周第一天、数字和日期格式、键盘布局、语音朗读
  - *设备*：系统和版本、浏览器、架构、屏幕、刷新率、显示器数量、显卡（WebGL 和 WebGPU）、CPU 线程、内存、触控、电池、网络连接、摄像头和麦克风（只计数，不打开）、视频解码、DRM、存储配额；新增：窗口和系统栏、WebGL 能力、音频硬件（采样率、声道）、生物识别（Windows Hello / Touch ID 可用与否，只问不用，以及浏览器对通行密钥的支持）、蓝牙适配器；设备型号（iPhone 和 iPad 看屏幕和 iOS 版本，MacBook 看屏幕和芯片，安卓看型号代码在 Google Play 设备表和 [MobileModels](https://github.com/KHwang9883/MobileModels)（国行机型；CC BY-NC-SA 4.0 协议，所以 `public/assets/m/` 也用这个协议）里的名字，`npm run models` 负责更新；笔记本看电池和显卡）
  - *浏览器设置*：配色、减少动画、色域和 HDR、DNT/GPC、Cookie、已授予或已拒绝的权限、PDF 阅读器、webdriver、广告拦截、会留下痕迹的扩展（加密钱包、开发者工具、Grammarly、Dark Reader、沉浸式翻译）、标签页历史、已装字体；新增：辅助功能偏好（高对比度、强制颜色、减少透明、反色）、打开方式（标签页、已安装的应用、全屏）、浏览器内置 AI（Gemini Nano 或 Phi 是否已下载、下载过哪些翻译语言）
  - *指纹*：Canvas、WebGL、音频、字体列表、综合指纹，以及浏览器是否会随机化它们；新增：JS 引擎（从报错的措辞看出 V8、SpiderMonkey 还是 JavaScriptCore，改 User-Agent 也改不掉）

所有行在读取之前就已画好，哪个嗅探器先返回就先填哪一行；那段话等所有空都齐了才一次填好，页面不会跳动。另有一个按钮可以模糊地址和位置，方便截图。

## 隐私

为了找出你的出口和 DNS 解析器，页面会直接访问几个外部服务（每行都写着名字：IPIP.NET、IP.SB、chatgpt.com、claude.ai 和 www.cloudflare.com 上的 Cloudflare trace、Cloudflare Radar、ip-api 的 DNS 服务器、两个 STUN 服务器），它们能看到你的地址，和你访问任何网站时一样。其余都在浏览器里读取，不会离开浏览器。Worker 只回答一个请求 `GET /api/me`，内容是它从这个请求里本来就能看到的：地址、Cloudflare 对它的 `request.cf` 数据、请求头（不含 Cookie 和 Cloudflare 自己加的）、地址的 PTR 记录和服务器时钟。不存储，不记日志。

## 自己部署

```bash
git clone https://github.com/yt1988/who-are-you
cd who-are-you
npm ci
npm run dev          # wrangler dev，http://localhost:8795（本地也会拿到 Cloudflare 的地理位置）
npm test             # 检查 public/ 是否最新，并跑单元测试
npm run smoke        # 用无头 Chrome 或 Edge 打开每种语言的页面：所有行、空格和检测都填上了，分享能用
npm run touch        # 手机宽度下，每个能点的地方都不小于 24×24 CSS 像素（WCAG 2.5.8）
npm run og           # 重新生成链接预览图（public/og/）
npx wrangler deploy  # 部署名为 who 的 Worker，再到控制台绑定自定义域名
```

`npm run build` 从 `src/` 重新生成 `public/`。用 `SITE_URL` 指定你自己的域名（canonical、sitemap、llms.txt）。`npm run tz` 从 tz 数据库更新时区到国家的对照表。
